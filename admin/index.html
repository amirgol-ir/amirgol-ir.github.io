پنل مدیریت سایت

برای ویرایش محتوای amiraligolchini.ir وارد شوید

کلید ورود را چطور بسازم؟
  1. وارد گیت‌هاب شوید و صفحه ساخت کلید جدید را باز کنید.
  2. در Token name یک نام بنویسید، مثلاً «پنل سایت». در Expiration مدت اعتبار را انتخاب کنید.
  3. در Repository access گزینه Only select repositories را بزنید و فقط مخزن amirgol-ir.github.io را انتخاب کنید.
  4. در Permissions روی Add permissions بزنید، Contents را اضافه کنید و آن را روی Read and write بگذارید.
  5. پایین صفحه Generate token را بزنید، کلید ساخته‌شده را کپی کنید و همین‌جا بچسبانید.
